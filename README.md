# First Principles Analysis Skill

一套把模糊问题转化为连续因果分析的 Skill。

v2 不再依赖一份不断增长的万能提示词，而是把分析拆成三层：

```text
所有问题共享的因果推理
+
不同主体需要优先检查的变量
+
带适用条件和失效边界的通用结论
```

目标是让输出既沿着明确逻辑推进，又不会机械套用同一个模板。

## 能处理什么

- 定义、识别和分类；
- 解释技术、行为、组织或市场结果怎样形成；
- 分析怎样达到一个目标；
- 比较方案和作出条件化判断；
- 混合的“为什么会这样 + 接下来怎么办”；
- 迭代 Skill、扩展主体指南和回归案例。

## 核心变化

### 1. “是什么”不再一律改成“为什么”

纯定义和分类直接回答边界；只有用户真正需要形成原因和机制时，才转入“为什么”。

### 2. 两条主要推理主线

解释已经存在的结果：

```text
结果
→ 长期条件
→ 直接触发
→ 中间作用过程
→ 维持和放大因素
→ 替代解释与证据
```

达成尚未实现的目标：

```text
目标和完成标准
→ 必要条件
→ 当前情况
→ 尚未成立的条件
→ 多条路径
→ 取舍、执行、验证和调整
```

### 3. 主体指南按需加载

当前包含：

- 人的行为与情绪；
- 群体与组织；
- 技术系统与产品；
- 行业市场与资源流动；
- 商业与赚钱；
- 制度与政策；
- 自然与生物系统。

指南只提供优先检查方向，不强制填充所有变量。

### 4. 通用结论改为结论卡

当前包含：

- 利益关系链；
- 资源分配；
- 反馈延迟与周期；
- 人的行为与情绪；
- 信息、能力与时间差；
- 资金流向。

每条卡都包含成立条件、失效范围、证据和常见误用。

### 5. 客观不等于替用户决定价值标准

Skill 不默认长期优于短期、稳定优于波动、持续优于一次性。方案比较使用用户明确选择的目标，同时客观说明法律、规则、安全、成本和后果。

## 目录

```text
SKILL.md
references/
├── core/          # 每次按问题方向读取的核心规则
├── subjects/      # 按主体读取的分析指南
├── conclusions/   # 按场景读取的通用结论卡
├── examples/      # 旧案例使用边界
├── 回归样例/      # v1 来源与回归基线
├── 第一性原理分析逻辑.md      # v1 原始来源
└── 第一性原理分析提示词.md    # v1 原始来源
evals/
├── README.md
├── rubric.md
└── regression-cases.json
scripts/
├── validate_skill.py
└── lint_language.py
```

## 使用

将本仓库作为 Skill 安装后，用户可以直接提出问题，例如：

- Agent 到底是什么，为什么会形成现在这种结构？
- 为什么同事在我指出错误后生气？
- 为什么团队总在争核心项目？
- 猪肉价格为什么可能周期波动？
- 我怎样利用 AI 赚钱？
- 我应该留在当前公司还是接受新 Offer？

Skill 会先在内部补全问题、选择推理方向和相关主体指南，再输出面向读者的分析，不展示内部路由脚手架。

## 验证

```bash
python3 scripts/validate_skill.py
python3 scripts/lint_language.py
```

模型输出质量按照 `evals/rubric.md` 和 `evals/regression-cases.json` 评审。结构校验不能替代实际生成回归。

## 原始来源

v1 的逻辑、提示词、经验和长篇案例继续保留，并由 `references/source-manifest.json` 校验哈希。v2 将它们视为历史来源和回归材料，而不是每次分析都完整加载的运行时提示词。
