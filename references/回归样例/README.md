# 回归样例说明

这些文件来自既有第一性原理分析实践，用于回归 Skill 的分析结构与行文逻辑。

它们不是统一事实标准，也不保证其中所有历史、源码、技术或商业判断在任何时间、版本与场景下都成立。使用方式是：

- 提取它们表现出来的分析能力；
- 对照 `evals/regression-cases.json` 检查结构性不变量；
- 不要求新输出逐字复现；
- 不把样例中的事实直接迁移到新问题；
- 不因当前外部知识变化而静默改写原始基线。
