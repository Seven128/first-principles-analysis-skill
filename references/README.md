# References

本目录分为四类材料。

## 1. `core/`：运行时核心规则

每次分析按问题方向读取。这里规定：

- 第一性原理的基本要求；
- 问题怎样补全和分类；
- “为什么”与“怎么做”的具体推理；
- 事实、推断、假设和评价标准；
- 输出与表达。

## 2. `subjects/`：主体指南

按当前问题需要读取。指南提供不同对象应优先检查的变量，不是固定答案。

## 3. `conclusions/`：通用结论卡

保存过去分析中可复用的候选规律。每条结论都有适用条件、失效边界和证据要求；使用前必须重新验证。

## 4. 原始来源与回归材料

- `第一性原理分析逻辑.md`
- `第一性原理分析提示词.md`
- `经验/`
- `回归样例/`

这些文件由 v1 来源材料保留，哈希记录在 `source-manifest.json`。默认不作为 v2 每次运行时的完整上下文；只有做 Skill 迭代、回归定位或用户明确要求对照时才读取。

`examples/旧案例使用说明.md` 说明旧案例中哪些能力可以学习、哪些表达和结论不能直接复制。
