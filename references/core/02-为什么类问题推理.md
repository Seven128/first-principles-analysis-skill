# 为什么类问题推理

## 1. 目标

“为什么”类分析解释一个已经存在的结果是怎样形成的。结果可以是：

- 技术或制度形成当前结构；
- 某个人产生情绪、作出选择或没有行动；
- 组织作出决策；
- 市场价格、资源或参与者行为发生变化；
- 自然系统出现某种现象。

它不是为一个现成答案补理由，而是从结果出现前的条件出发，逐步检查哪些变化足以解释结果。

## 2. 第一步：精确定义要解释的结果

避免分析模糊的“为什么这样”。明确：

- 具体发生了什么；
- 在什么时间和环境发生；
- 结果表现在哪些可观察事实上；
- 哪些只是他人的描述或评价；
- 需要解释“出现”“维持”“增强”“重复”还是“形成当前结构”。

不同结果可能需要不同原因。例如“为什么第一次生气”与“为什么长期容易生气”不是同一个问题。

## 3. 第二步：判断结果的性质

### 3.1 人为设计的结果

如技术、产品、协议、制度。

重点检查：

- 它承担什么任务；
- 原有能力为什么不够；
- 缺少什么条件；
- 当前机制怎样补足条件；
- 新机制带来什么后续问题；
- 哪些是逻辑需要，哪些是历史取舍。

### 3.2 有意识行为或选择

如合作、拒绝、辞职、隐瞒、分配项目。

重点检查：

- 对方认为有哪些选择；
- 每个选择预期带来什么收益、损失和风险；
- 对方掌握什么信息；
- 规则、关系和资源怎样影响选择；
- 行为是否真的经过明确权衡。

### 3.3 自动或半自动反应

如愤怒、恐惧、回避、习惯、冲动。

重点检查：

- 发生了什么刺激；
- 主体怎样感知和解释；
- 哪项预期、需要、身份、边界或控制感受到影响；
- 生理状态、长期压力和习惯是否放大反应；
- 是否存在无意识过程。

### 3.4 群体共同形成的结果

如组织文化、价格、行业周期、舆论。

重点检查：

- 不同参与者分别依据什么信息行动；
- 个体行动怎样相互影响；
- 是否存在反馈、延迟和资源限制；
- 群体结果是否与任何单个参与者的目标不同。

### 3.5 自然形成的结果

如生物、物理和生态现象。

重点检查物质、能量、信息、局部规则、环境约束、反馈和选择过程。不得把自然现象拟人化为“为了某目的而设计”。

## 4. 第三步：拆分原因层次

至少区分以下层次。

### 长期条件

让结果成为可能或更容易出现的背景，例如：

- 系统结构；
- 长期激励；
- 资源分布；
- 习惯与技能；
- 性格和长期压力；
- 技术限制；
- 环境规律。

### 直接触发

使结果在此时出现的事件，例如：

- 一次冲突；
- 一个需求变化；
- 一次价格信号；
- 一项新限制；
- 一个输入或故障。

### 中间作用过程

从条件和触发到结果之间发生了什么。必须尽量写清：

```text
输入或事件
→ 主体状态、判断或资源发生什么变化
→ 该变化为什么推动下一步
→ 结果怎样形成
```

### 维持因素

解释结果为什么持续、重复或稳定存在，例如：

- 正反馈；
- 转换成本；
- 权力和资源控制；
- 习惯强化；
- 缺少替代路径；
- 规则持续奖励同类行为。

### 放大和抑制因素

同一原因在不同条件下可能产生不同程度的结果。说明哪些因素会让结果更强、更弱或不发生。

## 5. 第四步：建立候选解释，而不是立即定论

复杂结果通常有多个可能原因。对每个候选解释检查：

```text
它能解释哪些已知事实？
不能解释哪些事实？
需要额外假设什么？
是否存在更简单的解释？
不同解释能否同时成立？
用什么新证据可以区分它们？
```

人的动机、情绪和经历尤其需要保留候选性质。

## 6. 第五步：区分逻辑重建和真实历史

分析人为设计物时，可以通过逻辑说明：

> 为完成某项任务，系统需要某类能力；原有能力缺少它，因此要增加某种机制。

这不自动证明：

> 历史上的设计者当时就是出于这个原因，并按照同样顺序完成设计。

涉及真实设计史、人物意图、版本变化和社会事件时，需要文档、记录或其他历史证据。

## 7. 第六步：机制按依赖关系出现

解释技术和制度时，不能先列完整组成，再逐项寻找理由。

应当写成：

```text
当前任务提出要求
→ 当时已有能力无法满足
→ 缺少某类条件
→ 引入一种机制
→ 机制改变了系统状态
→ 新状态又暴露新的问题
→ 再引入后续机制
```

无依赖关系的机制可以并列，但每一项仍需有独立的问题来源。

## 8. 第七步：检查反事实

可以通过反事实帮助检验原因：

- 若没有该条件，结果是否仍可能出现？
- 若条件存在但触发不存在，结果会怎样？
- 若换一个中间过程，是否也能产生结果？
- 若在相似环境中结果没有出现，差异在哪里？

反事实只能增强或削弱解释，不能在缺乏事实时制造虚构历史。

## 9. 停止追溯

原因可以无限向前追。满足以下条件时通常可以停止：

- 已经解释当前结果的关键形成过程；
- 继续追溯不会改变本次判断或行动；
- 更深原因缺少证据，只能产生猜测；
- 已经到达当前任务要求的对象层级；
- 用户没有要求讨论更长历史。

例如分析一次愤怒，通常先停在当前感知、预期、需要和处境。只有性格、长期模式或价值观本身需要解释时，才继续追溯成长经历。

## 10. 输出最小闭环

一份合格解释至少应让读者知道：

```text
需要解释的结果是什么
→ 结果出现前已经有什么
→ 哪些条件和触发最关键
→ 它们通过什么过程产生结果
→ 哪些因素维持或改变结果
→ 哪些结论是事实，哪些是推断
→ 还有哪些替代解释和证据缺口
```
