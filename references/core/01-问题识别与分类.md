# 问题识别与分类

## 1. 分析对象不是主题，而是完整问题

用户可能输入：

- 一个名词：Agent、情绪、猪周期；
- 一个主题：职场关系、AI 赚钱；
- 一个现象：同事突然生气；
- 一个目标：找到工作、提高收入；
- 一个交付要求：写篇文章、做个方案。

这些内容需要补成含义完整的问题。内部至少明确：

```text
主要对象：谁或什么需要被解释、改变或选择？
已出现或希望出现的结果：具体是什么？
时间：解释过去怎样形成现在，还是从现在走向未来？
环境：哪些外部条件会影响对象？
用户真正不知道什么：定义、原因、机制、路径、标准还是结论？
事实状态：哪些已知，哪些只是观点，哪些未知？
```

## 2. “是什么”不是单一问题类型

“X 是什么”至少可能表示四种需求。

### 2.1 定义与边界

用户需要知道：

- X 必须具备哪些属性；
- 不具备什么就不属于 X；
- X 与相邻概念有什么区别。

例如“什么是质数”。这类问题直接给出定义、边界和例子，不需要解释它为什么被设计出来。

### 2.2 识别与分类

用户要判断某个具体对象属于哪一类。

需要：

```text
分类标准
→ 当前对象的可观察属性
→ 与标准逐项比较
→ 得出结论和不确定性
```

### 2.3 当前事实

用户问“现在发生了什么”“这个文件是什么内容”。这属于事实确认，不必强行进入第一性原理形成分析。

### 2.4 形成原因与机制理解

用户表面问“Agent 是什么”，但真正想知道：

- 为什么需要它；
- 只有原有能力时为什么不够；
- 为什么形成当前结构；
- 各机制如何协作。

此时转入“为什么类问题”。

## 3. 两条主要推理方向

### 3.1 解释已经存在的结果

问题形式包括：

- 为什么会有 X；
- 为什么 X 是现在这样；
- 为什么他会生气；
- 为什么组织这样决策；
- 为什么价格会波动。

统一任务：

> 解释观察到的结果，是由哪些条件、变化和作用过程共同形成的。

### 3.2 达成尚未实现的目标

问题形式包括：

- 怎样做到 X；
- 怎么解决 Y；
- 如何从当前情况达到目标；
- 怎样赚钱、求职、增长、学习或设计。

统一任务：

> 从目标成立必须发生什么出发，找出当前还缺什么条件，并推出可以补足条件的路径。

## 4. 判断、比较与选择

“应不应该”“A 还是 B”“方案是否合理”不能直接用好坏回答。

先明确：

```text
用户想获得或避免什么结果？
有哪些必须满足的限制？
比较使用什么标准？
这些标准的优先级由谁决定？
A、B 分别怎样影响每项标准？
结论对哪些假设敏感？
```

没有明确评价标准时，给出条件化结论，不替用户选择价值排序。

## 5. 混合问题

一个请求可能同时包含：

- 解释现状为什么形成；
- 判断现状是否有问题；
- 设计未来怎样改变。

正确处理：

```text
第一条链：过去的条件与变化 → 当前结果
第二条链：当前情况 → 未来目标所需条件 → 行动路径
```

先分别成立，再说明二者怎样衔接。

## 6. 主要对象与外部条件

主要对象是发生变化、作出行为或需要达到目标的对象。

例如“我怎样找到工作”：

- 主要对象是求职者；
- 企业、市场和政策是影响求职者结果的外部条件。

例如“Leader 为什么把项目交给某人”：

- 主要对象可以是 Leader 的决策；
- 团队规则、绩效、候选人能力和关系是影响决策的条件。

不要在分析中途无说明地把主要对象换成市场、公司或另一个人。

## 7. 抽象程度

问题要具体到能够指导推理，又不能细到提前写入答案。

过粗：

- 环境复杂；
- 竞争激烈；
- 人性如此。

过细：

- 某个未来模块缺少某字段；
- 某个方案应该使用某个类名；
- 某人的童年一定发生过某件事。

合适表达：

- 求职者的能力尚未被招聘方稳定识别和验证；
- 只有模型输出时，系统不能直接改变外部状态并依据结果继续行动；
- 当前证据只能说明对方可能把事件理解为不尊重，不能确认其深层经历。

## 8. 信息不足时的处理

### 可以继续分析

缺失信息只会影响具体分支，不改变主要问题时：

- 明确暂定范围；
- 使用“若……则……”；
- 给出需要补充的数据。

### 应当澄清

以下信息缺失会使答案方向完全不同：

- 主要对象不明确；
- 目标含义不明确；
- 时间范围不同会改变事实；
- 用户要求个性化行动，但当前状态完全未知；
- 选择问题没有任何评价标准。

只问最少且真正必要的问题。

## 9. 路由检查

正式分析前确认：

- 这是定义、解释、行动还是选择问题？
- “是什么”是否真的需要转成“为什么”？
- 主要对象是谁？
- 结果是什么？
- 时间方向是什么？
- 是否需要多个主体指南？
- 是否存在用户未经证明的前提，需要先检查？
