# 关键推理节点反向校验

## 1. 位置与目的

这一步属于完整推演内部，发生在候选原因、必要条件、方案路径或小结论已经形成之后，进入正式因果链之前。它不属于文章成稿层，也不要求把检查过程原样展示给读者。

目的不是为了反驳所有结论，而是主动发现：

- 被省略的前提条件；
- 把促进条件写成充分条件；
- 把一种实现写成必要条件或排他的实现路径；
- 反向因果、共同原因和替代解释；
- 结论强度超过证据强度；
- 适用范围、时间范围或对象范围没有写清。

每个关键论点至少完成一次针对其实际关系的反证式检查。粒度、复用和停止条件按第 7 节执行；这里的反证包括寻找反例、检验替代解释和核对相反证据，不把所有经验问题都写成形式逻辑证明。

候选节点只有经过修复后，才能作为确定程度相匹配的节点进入完整因果链。

## 2. 先判断节点声称的关系

对关键节点，先用普通语言说明它究竟声称什么。常见关系包括：

- **必要条件**：没有 A，B 就无法成立；
- **充分条件**：只要 A 成立，在声明的条件和范围内 B 就会成立；
- **促进条件**：A 会提高 B 出现的概率、速度或程度，但不能保证 B；
- **一种实现路径**：A 能补足 B 所需要的某项条件，但还有其他办法；
- **伴随关系**：A 与 B 同时出现，当前尚不能确认因果方向。

不能仅凭“因为、所以、必须、只要”等句式判断关系。必须结合当前事实、作用过程、范围和证据强度。

## 3. 按节点关系选择反向检查

以下四类是检查工具，按节点声称的关系选择。必要条件重点找替代路径，充分条件重点找结果未成立的情况，因果解释检查替代原因；纯事实与数值判断按第 7 节核实来源和计算，不机械执行无意义的因果测试。

### 3.1 A 已经存在，但 B 没有出现

寻找或构造当前范围内可能成立的情况：

```text
A 成立
但 B 不成立
```

它主要检查 A 是否足以产生 B。

若这种情况可能存在，通常说明：

- A 不是充分条件；
- 还缺少共同成立的条件；
- 中间作用过程没有真正发生；
- 存在抵消或抑制因素；
- 原结论只能写成概率或程度变化。

修复方式通常是：

```text
A + 必要的环境或中间条件
→ B
```

或者把“一定导致”降低为“在这些条件下提高概率、速度或程度”。

### 3.2 A 不存在，但 B 仍然出现

寻找或构造当前范围内可能成立的情况：

```text
A 不成立
但 B 成立
```

它主要检查 A 是否真的是必要条件，或者只是实现 B 的一种路径。

若这种情况可能存在，通常说明：

- A 不是必要条件；
- 存在替代原因或替代路径；
- 当前分析把具体实现误写成了上位条件；
- 真正必要的是 A 与其他路径共同满足的更高层条件。

修复方式通常是：

```text
A1 或 A2 或 A3
→ 共同补足条件 X
→ B
```

例如，“防止数据丢失”可能需要独立、可恢复且经过验证的数据副本；主从复制只是满足该条件的一种实现，不自动是唯一必要实现。

### 3.3 检查反向因果和共同原因

继续检查：

```text
是否可能是 B 影响 A？
是否存在 C 同时促成 A 和 B？
A 是否只是 B 的结果或伴随现象？
A、B 是否可能相互强化？
```

如果多个方向都能解释现有事实，不得仅凭相关性选定其中一个。应说明候选关系，并指出能够区分它们的新增证据或观察。

### 3.4 检查命题范围与强度

反例的作用取决于命题类型：

- 对声称无例外的严格命题，例如使用“所有、一定、只要”等表述时，一个处于同一范围内的真实反例就足以推翻原表述；
- 对“通常、更可能、提高概率、平均而言”等概率命题，单个反例不能推翻关系，需要比较相近条件下的发生率、程度或作用机制；
- 对历史意图命题，逻辑上需要某项能力不能证明历史设计者当时就是因为该原因作出选择，仍需历史材料；
- 对评价命题，反向检查不能替用户新增评价标准。

## 4. 使用真实对照增强反向校验

有可比较对象或时间段时，可以用真实对照替代纯粹想象反例。对照只补强关键节点校验，不要求每个问题都做竞品研究或历史研究。

### 4.1 相同目标、不同实现

寻找没有采用 A、但通过其他路径仍达到 B 的对象：

```text
目标 B 相同
→ 对象 1 使用 A
→ 对象 2 不使用 A，而使用 A2
→ 两者都补足更上位条件 X
```

这类对照用于检查 A 是否只是实现 X 的一种路径。比较前必须确认目标口径、故障范围、成本约束和完成标准相近。

### 4.2 相同机制、不同结果

寻找都采用 A、结果却不同的对象：

```text
对象 1 使用 A → B 成立
对象 2 使用 A → B 不成立或程度明显不同
```

这类对照用于发现遗漏的共同条件、执行质量、环境差异、抑制因素或中间过程。不能因为机制名称相同，就假设实际实现强度和使用条件相同。

### 4.3 同一对象、不同时间

比较机制、环境或结果发生变化前后的状态：

```text
时间 1：条件组合 C1 → 结果 B1
时间 2：条件组合 C2 → 结果 B2
```

它可以帮助定位真正改变结果的变量，也容易受到同时发生的其他变化影响。需要检查版本、规模、用户结构、外部环境和测量口径，不能把时间先后直接当作因果。

### 4.4 真实选择与放弃

在产品、商业、制度和组织问题中，用户、客户或参与者的选择与放弃可以提供价值、成本、信任、风险和切换条件的证据。但真实行为仍可能同时受到渠道、价格、合同、默认选项和信息不完整影响，不能把“选择了 A”直接解释为“认同 A 的全部特性”。

### 4.5 对照选择与历史可见选项

选择横向对象时说明为什么可比，并主动检查是否只挑选支持原结论的成功案例。分析历史决策时，还要确认当时实际可见、可获得的选项；今天存在的替代方案不能被直接当作过去决策者当时能够采用的方案。

## 5. 逆否命题不能与否命题混淆

若原命题是：

```text
A → B
```

它的逆否命题是：

```text
非 B → 非 A
```

在对象、条件和范围完全相同的严格命题中，二者逻辑等价。

下面这个命题则是原命题的否命题：

```text
非 A → 非 B
```

它不与原命题等价。否命题不成立，不能直接证明原命题不成立；它检查的是 A 对 B 是否必要，以及是否存在不经过 A 仍能得到 B 的替代路径。

例如：

```text
开车上班 → 不迟到
```

“不开车上班 → 一定迟到”不是它的逆否命题。坐地铁也可能不迟到，只能说明开车不是“不迟到”的必要条件，不能由此证明“开车时不会迟到”本身必然为假。

同时还要检查“开车但迟到”的情况。若堵车、出发过晚或车辆故障仍会导致迟到，就说明“开车”本身也不是充分条件。更准确的节点应补充出发时间、道路状态等条件，或者降低为概率性结论。

### 5.1 形式反证与经验性反证检查

形式反证法先假设待证命题不成立，再从独立成立的前提推出矛盾；不能把待证结论偷偷放进前提。若讨论严格命题是否可被推翻，寻找同范围内满足前件却不满足后件的反例，是另一种检验方向，不能混用。

产品效果、人的动机、经营预测等经验命题通常不能仅靠设想相反情况证明。应寻找最有力的失败情形、相反证据或竞争解释，并判断现有材料能否区分。未找到反例只表示本次检查尚未推翻它；不能写成已经证明必然正确。假设性反例只能揭示条件缺口，不能冒充实际发生的案例。

## 6. 校验失败后的修复动作

发现反例或替代路径后，不能只写“原结论错误”。应根据失效原因执行一种或多种修复：

```text
缺少条件
→ 补充必要条件或中间过程

存在替代路径
→ 将一种实现改成多条路径之一，并上提真正必要条件

只有概率影响
→ 降低结论强度，说明比较范围和影响方向

存在共同原因或反向因果
→ 拆分候选解释并提出区分证据

范围过宽
→ 缩小对象、时间或环境范围

证据不足
→ 标记为待验证假设，不进入确定事实链

出现直接反例且无法修复
→ 删除该节点
```

## 7. 哪些节点需要强制检查

### 7.1 用会否改变判断来识别关键论点

检查单位是一个可以单独核实、支持或推翻的命题，不是一个句子、段落、标题或每个名词。命题至少能说明对象、关系、范围和依据。

将它暂时置为未知、取反或改为合理的替代值：若会实质改变核心答案、方案排序、是否继续、关键适用范围、重要代价或应向读者表达的结论强度，它就是关键论点。不改变这些输出的微小置信波动，不单独触发完整校验。包括：

- 直接支撑最终结论的节点；
- 决定后续分析分支或行动选择的节点；
- 主链中使用“必须、只有、只要、一定”等无例外表述的节点；
- 从经验、案例、主体指南或结论卡引入，并实际用于支持答案的节点；
- 缺少直接证据、主要依赖推断的关键因果桥梁；
- 会导向高成本、难以逆转或高风险行动的节点。

决定权限、合法性、安全、可行性或盈亏的事实和数值同样属于关键论点，不能因其不是因果句而漏检。多个独立依据共同支持一个结论时，也要检查每条被声称足以成立的依据及它们的组合，不能因为删去其中一条仍有其他依据，就把全部依据都排除。

用户选择的目标和偏好用于确定标准，不需要证明其客观优越；若声称某做法能实现该目标，仍要检查这条事实或因果判断。普通定义、已确认且低影响的事实连接、修辞和例子名称只做准确性检查。

### 7.2 拆到能独立改变结论的最小命题

一句话包含证据来源、因果效果、适用范围或行动许可等不同依据时，按能够独立失效的关系拆开。例如“有人愿意用，所以可以收费并盈利”至少涉及使用价值、支付行为、交付与收费条件、成本收入关系，不能用一次整体质疑代替各节点检查。

沿关键结论向下拆到：每个节点只有一个待判关系，其依据已经是当前可核实材料、适用定义，或明确保留的假设；再细分不会改变判断和修复动作时停止。不要把同一关系拆成词语级证明，也不要把多个独立失败原因藏进一个大节点。

### 7.3 每个关键论点的一轮最低检查

一轮检查完成四件事，保留简短结论记录即可，不保存逐步思考过程：

1. **明确命题**：对象、范围、关系类型及当前证据。
2. **尝试推翻**：提出一个最有力、与本题范围相符的失败情形或竞争解释，并说明哪项观察能区分它与原判断；已有明确反例时直接使用。
3. **对照材料**：用已有可靠材料、独立计算或必要的针对性查询核对；明确哪些只是可能情形，哪些已有证据。
4. **修复结论**：保留为有范围的判断，或补条件、降强度、换路径、标记未决、删除；修复影响下游时同步重算下游结论。

检查方式随命题变化：

| 命题 | 本轮优先检查 |
| --- | --- |
| 声称必要条件或排他实现 | 条件缺席时，是否仍有满足同一目标和约束的替代路径。 |
| 充分条件或效果保证 | 条件具备时，最可能在哪个环节仍然失败。 |
| 因果、概率或平均效果 | 共同原因、反向因果、样本选择或比较口径能否同样解释结果；不用一次失败推翻概率关系。 |
| 关键事实、规则或许可 | 原始来源是否真的覆盖该主体、动作、对象、时间和范围，是否存在相反证据；技术可用不能代替获准使用。 |
| 数值、成本或排序阈值 | 独立复核单位、分母、计算和关键输入；在有依据的范围内改变输入，检查结论何时翻转，不编造精确区间。 |

“也许有例外”“再验证一下”不构成一轮检查。相同证据的多篇转述也不等于独立验证。

### 7.4 按依赖复用，只升级尚未解决的关键分歧

同一命题、同一依据和同一适用范围只查一次，下游引用其结果。共享前提先查一次，再逐一检查各分支独有的作用关系；不同主体、版本、收费方式或结果指标不能冒充同一个命题复用。新证据或范围变化时，只重查受影响节点及其下游。

默认先用现有材料完成一轮。确有证据缺口时，围绕能改变决定的问题做一轮定向取证，可并行查询独立来源；只有发现实质冲突、决定性缺口或高后果结论仍不稳时，才继续追加检查。第二轮起必须能说明新增证据将区分什么，不能无限搜索直到得到喜欢的答案。

当关系已被修复、证据足以支持当前范围，且剩余未知不会改变本次判断时停止。无法核实的关键项保留为未决并限定受影响建议，给出下一步证据或条件分支，不能因达到时间预算而标记通过。低成本试验不能替代必须先满足的权限或安全条件。

不设“只检查前三个论点”之类总数上限。细度由结论依赖决定，耗时通过按需读取、共享检查、定向取证和停止无信息增量的追问控制；不声称固定检查次数能保证具体运行时长。

## 8. 最终输出边界

反向校验是内部推理工具。默认不向读者展示完整检查表、符号推导或所有被淘汰的节点。

但校验产生的有效结果必须进入最终分析：

- 补充后的条件和中间过程；
- 发现的替代原因或替代路径；
- 降低后的结论强度；
- 缩小后的适用范围；
- 仍需验证的证据缺口。

用户需要文章、报告或完整方案时，应先完成这一步并锁定修复后的因果链，再进入成文层。成文层只能改变信息选择和表达，不能恢复已经被校验淘汰的强结论。
