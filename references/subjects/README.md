# 主体指南

主体指南回答：面对某类对象时，哪些变量通常值得优先检查。

其中产品发现与验证、商业化与合规是“已知经验”环节的场景方法。前者补充决策依赖、观察条件和证据分工；后者把实际行为与权利义务、证据和成本对应。方法不直接证明结论，只有命中本题未知时才读取。

它们不是固定模板，也不是答案库。使用规则：

1. 先使用通用问题识别和因果主线；
2. 再选择一个或多个相关主体指南；
3. 只保留当前事实能够支持的方向；
4. 没有证据的内容只能作为候选解释；
5. 新主体可以组合已有指南，不要求现实世界被完全穷举。

每份指南至少包含适用问题、优先检查、不能直接假设、证据与验证及常见错误；主体特点与常见因果链按需要补充。具体可以包含：

- 适用问题；
- 主体特点；
- 优先检查；
- 常见因果链；
- 不能直接假设；
- 证据与验证；
- 常见错误。
