# 群体与组织

## 适用问题

- 公司、团队、社群或机构为什么形成某种关系和决策；
- Leader 为什么分配项目、绩效、预算或机会；
- 为什么出现联盟、冲突、推诿、信息封锁或组织文化；
- 怎样改变团队协作、治理或资源配置。

## 主体特点

组织结果通常由多个参与者共同形成。每个人拥有不同信息、目标、权限、资源和风险，最终结果可能并非任何单个人完整设计的结果。

需要同时看：

- 正式规则；
- 实际执行；
- 权力和评价关系；
- 资源分配；
- 人际信任和联盟；
- 信息流动；
- 外部组织与上级输入。

## 优先检查

1. 有哪些角色和参与者？
2. 每个角色希望获得或避免什么？
3. 当前真正稀缺的资源是什么？
4. 谁拥有资源、评价权、批准权和否决权？
5. 谁的结果依赖谁？
6. 成功和失败分别由谁获得收益、承担成本？
7. 正式规则与实际规则是否一致？
8. 信息由谁产生、过滤和传递？
9. 信任、历史合作和人际关系怎样改变风险判断？
10. 上级、客户、政策和其他组织输入怎样改变内部行为？

## 常见因果链

### 资源分配决策

```text
组织目标与评价规则
→ 当前可分配资源有限
→ 决策者要承担交付和评价结果
→ 候选人的能力、可靠性、关系、可控性与机会成本不同
→ 决策者根据其掌握的信息作出分配
→ 分配结果反过来改变经验、绩效和未来竞争位置
```

### 关系链形成

```text
参与者结果相互依赖
→ 评价权、资源和信息分布不均
→ 参与者需要合作、交换、服从、谈判或结盟
→ 重复互动形成信任、声誉和非正式规则
→ 形成稳定或暂时的关系链
```

### 组织惰性

```text
现有流程承载责任和利益
→ 改变会产生协调成本与失败风险
→ 决策者承担改变成本但收益可能由他人获得
→ 缺少足够激励或授权
→ 旧流程持续存在
```

## 不能直接假设

- 所有决策都只为个人晋升或绩效；
- 正式职位等于实际影响力；
- 分配结果不公平就必然存在恶意或利益输送；
- Leader 掌握完整信息；
- 团队目标与个人目标一致；
- 组织行为等于领导者个人意图；
- 稀缺资源一定是钱，也可能是时间、注意力、机会、信用和风险额度。

## 证据与验证

检查：

- 绩效和晋升规则；
- 预算、项目和人员分配记录；
- 决策者承担的责任；
- 不同人员的能力、可用时间和历史交付；
- 沟通记录和信息传递；
- 多次决策是否呈现一致模式；
- 规则变化后行为是否变化；
- 是否存在未被观察到的约束。

## 常见错误

- 只用“人情世故”解释全部组织行为；
- 只看组织公开目标，不看个人激励；
- 只看个人利益，不看任务风险和责任；
- 没有定义资源就讨论资源争夺；
- 把个体动机直接相加成群体结果；
- 把一次分配结果上升为永久关系结构。
