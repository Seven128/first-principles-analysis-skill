# 人的行为与情绪

## 适用问题

- 为什么某个人生气、恐惧、焦虑、回避或兴奋；
- 为什么做、拒绝、拖延或重复某件事；
- 怎样改变自己的行为；
- 怎样理解关系冲突和沟通结果。

## 主体特点

人的行为并不总是经过完整、理性的目标计算。行为可能同时受到：

- 主观理解；
- 预期、需要和利益；
- 身份、边界和关系；
- 习惯、冲动和自动反应；
- 生理状态与长期压力；
- 社会规范和从众；
- 可见选项、信息和控制感；
- 过去经历形成的判断方式。

分析重点不是假装读心，而是从可观察事实建立多个候选解释。

## 优先检查

1. **事件**：客观发生了什么？
2. **感知**：对方实际注意到什么？是否掌握完整信息？
3. **解释**：对方可能把事件理解成什么？
4. **比较标准**：事件与什么预期、规则或自我认识发生冲突？
5. **需要与利益**：安全、尊重、控制、归属、资源、效率或其他结果是否受影响？
6. **情绪评价**：对方是否判断为损失、威胁、不公、冒犯、失控或机会？
7. **行为选项**：他认为自己有哪些应对办法？
8. **自动因素**：习惯、生理状态、疲劳、压力、冲动或群体影响是否参与？
9. **长期形成**：只有当前模式需要更深解释时，再检查成长经历和长期强化。

## 常见因果链

### 情绪

```text
外部事件
→ 主体感知到的事件
→ 对事件的解释
→ 与预期、需要、身份、边界或控制感比较
→ 形成损失、威胁、不公或机会判断
→ 产生情绪和行动倾向
→ 在当前能力与环境下作出行为
```

### 有意识选择

```text
当前目标或想规避的结果
→ 可见选项
→ 对收益、成本、风险和他人反应的预期
→ 规则、关系和资源限制
→ 选择并行动
```

### 拖延或不行动

```text
长期目标存在
→ 当前行动带来即时成本、模糊或负面情绪
→ 不行动带来即时缓解
→ 延迟后果尚未发生
→ 回避得到短期强化
→ 行为重复
```

这只是候选链，不能替代当前事实。

## 不能直接假设

- 所有行为都有明确目的；
- 受益者一定是有意为之；
- 生气一定因为预期未满足；
- 沉默就是同意或敌意；
- 一次行为能够证明人格；
- 价值观一定来自某段童年经历；
- 对方知道全部事实并作出理性最优选择；
- 用户对事件的理解等于对方的理解。

## 证据与验证

可使用：

- 当事人的直接说明；
- 行为发生前后的具体事件；
- 类似条件下行为是否重复；
- 不同解释能否解释全部事实；
- 通过开放问题确认对方如何理解事件；
- 行为在规则、利益或关系变化后是否改变；
- 必要时的专业评估。

判断童年、人格和深层动机需要更强证据，不能由单次事件直接推出。

## 常见错误

- 直接跳到“他就是自私、嫉妒、缺爱”；
- 把可能获益等同于真实动机；
- 只看客观事件，不看主观解释；
- 只讲心理，不看现实利益、权力和规则；
- 只讲利益，不看情绪、习惯和认知；
- 无限追溯过去，反而没有解释当前过程；
- 给出唯一动机，不保留替代解释。
