# 制度与政策

## 适用问题

- 为什么出现某项制度、规则、治理机制或政策；
- 规则怎样改变参与者行为；
- 为什么制度没有达到声明目标；
- 怎样设计或调整规则。

## 主体特点

制度本身不会自动产生结果。它通过：

- 权限；
- 奖励和惩罚；
- 信息披露；
- 程序和审核；
- 执行能力；
- 参与者预期；
- 申诉和纠错；

影响具体行为。实际结果还取决于参与者如何适应、规避或利用规则。

## 优先检查

1. 制度要改变谁的什么行为？
2. 希望得到什么结果？
3. 参与者原本为什么采取当前行为？
4. 规则改变了哪些收益、成本、权限或信息？
5. 谁负责执行，怎样发现违规？
6. 执行者自身的激励是什么？
7. 参与者可以怎样规避、转移或重新定义行为？
8. 正式规则与实际执行差异是什么？
9. 规则产生哪些非预期后果？
10. 纠错、申诉和更新机制是什么？

## 常见因果链

```text
原有行为产生某种结果
→ 制度改变行为的收益、成本、权限或可见性
→ 参与者重新选择或适应
→ 执行者检测并处理
→ 形成实际结果
→ 规避和副作用出现
→ 制度继续调整
```

## 不能直接假设

- 颁布规则等于规则被执行；
- 违规成本写得高就有足够威慑；
- 制度目标等于设计者唯一动机；
- 所有参与者理解规则一致；
- 参与者不会适应和规避；
- 正式组织图代表真实权力；
- 一次改革可以永久解决动态问题。

## 证据与验证

检查：

- 规则原文和适用范围；
- 执行流程与资源；
- 实际处罚、奖励和申诉记录；
- 参与者行为变化；
- 执行前后数据；
- 规避方式和非预期结果；
- 不同群体承担的成本和获得的收益。

## 常见错误

- 只解释规则文本，不解释执行过程；
- 只看公开目标，不看激励和权力；
- 把制度存在当成有效证明；
- 忽略执行者和被管理者之间的信息差；
- 用道德评价替代行为机制；
- 把局部有效扩展为所有环境有效。
