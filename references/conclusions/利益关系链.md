# 利益关系链

## 更准确的表述

在资源、评价、权限或结果相互依赖的群体中，参与者的行为通常会受到预期收益、损失和依赖关系影响。因此分析职场、组织、合作和资源分配时，利益结构是必须检查的方向之一，但不是无需证据即可认定的唯一原因。

## 为什么可能成立

当一个人的结果由他人控制或影响时，他的选择会受到这种关系约束。例如：

```text
上级控制绩效、机会或资源
→ 下级的部分结果依赖上级判断
→ 下级会考虑上级偏好、规则和关系
→ 重复互动形成合作、服从、谈判或联盟
```

决策者同样需要考虑自身绩效、责任、风险和上级评价。

## 适用范围

- 公司和团队；
- 供应商和客户；
- 合作组织；
- 社群治理；
- 权限、预算、机会和评价分配；
- 结果相互依赖的长期关系。

## 分析时优先检查

- 谁评价谁；
- 谁控制资源和机会；
- 谁承担失败成本；
- 谁获得成功收益；
- 谁可以影响规则；
- 短期利益与长期关系是否冲突；
- 信息、信任、责任和价值观是否同时参与。

## 成立条件

至少存在一种实际依赖：

- 资源依赖；
- 评价依赖；
- 权限依赖；
- 信息依赖；
- 合作结果依赖；
- 风险承担依赖。

## 失效或弱化

- 参与者几乎没有相互依赖；
- 规则完全自动、透明且无法被个人影响；
- 当前行为主要由紧急事件、生理状态、习惯或错误认知触发；
- 利益影响很小，而职业责任、价值观或关系承诺更强；
- 用户观察到的关系只是偶发事件。

## 证据

- 绩效、预算、项目和晋升规则；
- 决策权与实际执行记录；
- 行为在利益条件变化后是否变化；
- 多次相似决策；
- 参与者直接说明；
- 是否存在其他更简单解释。

## 常见误用

- “所有职场决策都只为晋升”；
- “谁获益谁就是幕后动机”；
- “存在上下级关系就一定存在利益输送”；
- 用利益解释取代能力、责任、信任、情绪和信息分析。
