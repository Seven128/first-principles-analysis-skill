# 资金流向

## 更准确的表述

分析“怎样赚钱”时，先识别钱从哪里来、由谁决定分配、获得钱必须满足什么条件，再分析主体能够通过什么路径满足这些条件。

“做产品—用户付费”只是其中一条分支，不是赚钱问题的默认答案。

## 为什么可能成立

收入成为事实，至少需要：

```text
存在资金来源
→ 存在支付者或分配规则
→ 主体满足支付或分配条件
→ 双方或系统完成交易、分配和结算
→ 收入扣除相关成本后形成主体实际结果
```

## 适用范围

- 工资和项目收入；
- 产品和服务；
- 平台分成；
- 广告；
- 佣金和撮合；
- 投资和资产收益；
- 资助、补贴和奖金；
- 版权、授权和租赁；
- 风险承担和流动性提供。

## 分析时优先检查

- 钱由谁持有；
- 谁决定支付；
- 为什么支付；
- 支付条件由市场、合同、平台还是制度决定；
- 主体提供什么结果或承担什么风险；
- 怎样触达、成交和结算；
- 收入与利润、现金流、资产增值的区别；
- 成本、波动、时间和限制。

## 成立条件

- 存在真实支付者或分配机制；
- 主体有资格或能力满足条件；
- 资金流动渠道可用；
- 预期收入没有被成本完全抵消；
- 关键法律、合同和平台条件允许执行。

## 失效或弱化

- 用户有需求但不愿付费；
- 支付者与使用者不是同一人，且决策链未打通；
- 平台规则可以随时改变；
- 收入高但履约和获客成本更高；
- 资金只是账面价值，无法结算；
- 收益高度依赖不可控事件。

## 证据

- 实际支付行为；
- 合同和平台分配规则；
- 单位收入和各项成本；
- 结算周期和坏账；
- 需求、支付能力和替代方案；
- 风险和波动数据。

## 常见误用

- 把需求等于支付意愿；
- 把收入等于利润；
- 只列赚钱方法，不分析资金来源；
- 只看产品，不看决策者、渠道和结算；
- 默认所有路径都需要用户直接付费；
- 用价值判断代替收益、成本和约束比较。
