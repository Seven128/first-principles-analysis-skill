# 资源分配

## 更准确的表述

只要一个群体或系统中存在有限、被多个参与者需要、且获取方式受到规则或他人控制的资源，就会形成某种资源分配过程。参与者行为会受到资源数量、获得条件、分配权和未来预期影响。

## 为什么可能成立

资源无法同时满足所有需求时，必须通过价格、规则、权力、顺序、竞争、谈判、抽签、关系或其他方式决定流向。分配结果又会改变参与者未来的能力和位置。

```text
资源有限
→ 多个参与者提出需求
→ 某种规则或决策者进行分配
→ 各方获得不同结果
→ 结果改变未来能力、利益和竞争行为
```

## 适用范围

- 预算、利润和现金；
- 时间和注意力；
- 好项目、绩效名额和晋升机会；
- 人员、设备和算力；
- 流量、曝光和渠道；
- 信息、决策权和风险额度；
- 行业产能、库存和市场份额。

## 分析时优先检查

- 当前问题中“资源”具体指什么；
- 资源总量是否真的有限；
- 谁拥有或产生资源；
- 谁决定分配；
- 分配依据是什么；
- 获得资源会产生什么后续优势；
- 是否有外部资源可以进入；
- 资源是否可以替代、共享或扩张。

## 成立条件

- 资源对结果有实际价值；
- 多个参与者需要它；
- 资源不能无成本无限复制；
- 存在可观察的获得或分配过程。

## 失效或弱化

- 资源并不稀缺；
- 不同参与者需要的并非同一资源；
- 外部输入能够快速扩大供给；
- 资源可以共享且边际成本很低；
- 当前冲突实际来自身份、规则不清或沟通，而非资源不足。

## 证据

- 资源数量、需求和使用记录；
- 分配规则和决策记录；
- 参与者为获取资源付出的行为；
- 资源变化后行为是否改变；
- 是否存在未被识别的替代资源。

## 常见误用

- 不定义资源就说“这是资源争夺”；
- 假设所有资源都是零和；
- 把一次分配当成永久结构；
- 忽略外部输入和资源扩张；
- 把分配不均直接等同于不合理或恶意。
